# Контроль качества машинно-читаемого контента

## Подготовлено

- 113 страничных записей workbook; все 26 уроков сгруппированы по страницам.
- 339 записей индекса упражнений и 339 строк общей очереди проверки.
- Для уроков 1–5 подготовлены отдельные файлы `workbook-lesson01-content.jsonl` … `workbook-lesson05-content.jsonl`: всего 80 упражнений. Границы заданий и текст сверены со сканами workbook pp. 4–21; ответы сверены со сканами ключей pp. 102–103.
- Для этих 80 упражнений в очереди внесены нормализованные формулировки и ответы, сняты общие blockers. Единственное исключение — L02/E04: печатный ключ даёт „jesteś” при формальном обращении „pan”; грамматически ожидается „jest”. Исходное чтение сохранено, вопрос помечен для редакторского решения.
- В уроках 1–5 связаны 22 аудиофайла. Сопоставление сделано по явным кодам урока и упражнения в именах; сами аудиозаписи не транскрибировались.
- Для заданий с иллюстрациями сохранены ссылки на исходные страницы и добавлено поле `visual_dependency`; отдельные цифровые кропы картинок пока не подготовлены.
- Ответ L01/E15 исправлен по ключу: пункты 3, 12 и 16 — „cyna”, „ciarki”, „żelka”. В L04/E07 восстановлено „robisz”. В L05/E11 и E17 исправлены падежные формы. Слабочитаемое соответствие L05/E16 подтверждено по увеличенному скану как 9→j.
- 274 страничные записи teacher manual; 26 диапазонов уроков.
- 432 блока упражнений учебника извлечены из текстового PDF, с ID, номером страницы и печатными аудиокодами.
- Два OCR-прохода сверены для workbook pp. 4–108 и teacher-guide lesson pages.

## Готовность

Уроки 1–5 имеют структурированные записи заданий и ответов, связанные аудиофайлы и ссылки на сканы-источники. Они готовы для импорта в разработку платформы как содержимое с источниками. Перед автопроверкой нужно решить отмеченное расхождение ключа L02/E04. Для визуальных упражнений интерфейсу потребуется использовать исходные иллюстрации/кропы страниц; для аудиоупражнений — подключить файлы из `audio_assets`.

Уроки 6–26 пока представлены OCR страницами и индексами, без полной сверки текста и ответов на уровне заданий. Общий пакет пригоден для staging импорта; весь курс ещё не готов к автопроверке.
