# Текстовые выгрузки книг

- `01-coursebook.txt` — 172 страницы учебника; текст извлечён из PDF. Сохранены маркеры `--- PAGE N ---`.
- `02-workbook-ocr.txt` — 113 страниц тетради; распознано OCR со сканов. Сохранены маркеры страниц.
- `03-teacher-manual-ocr.txt` — 274 страницы пособия преподавателя; распознано OCR со сканов. Сохранены маркеры страниц.

В OCR-текстах возможны ошибки распознавания польских букв, диакритики, цифр и вёрстки. Для проверки конкретных ответов и кодов заданий сверяйтесь с исходными PDF из `assets`.
- `04-coursebook-rtfd.txt` — текст из добавленного `assets/uchebnik.rtfd/TXT.rtf`; конвертирован из RTF, 172 страницы разделены переводами страниц. Это полная текстовая версия учебника до печатной стр. 177 (урок 26). Пакет RTFD также содержит 44 вложения TIFF; они остаются в исходной папке `assets/uchebnik.rtfd` и в TXT-выгрузку не включены.
